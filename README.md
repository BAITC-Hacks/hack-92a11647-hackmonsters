# «Аким на 5 часов» — HackMonsters

Симулятор управления Астаной: React-интерфейс → FastAPI-калькулятор → объяснение OpenAI. Каталог, районы, стоимость, эффекты, синергии и ограничения берутся из `data/city.json`. Браузер не вычисляет показатели и Score. OpenAI получает уже рассчитанный результат, а не исходное описание проблемы.

## Запуск

Нужны Python 3.11+, Node.js 22.18+ (или 24+) и pnpm 11.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
pnpm install --frozen-lockfile
```

В локальном `.env` задайте:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o
```

FastAPI автоматически читает `.env` из корня репозитория. Переменные окружения имеют приоритет. После смены ключа перезапустите backend. `.env` исключён из Git; `.env.example` содержит только пустые шаблоны. Не добавляйте ключи в `VITE_*`: такие переменные могут попасть в браузер.

Для показа единого приложения:

```bash
pnpm build
python -m uvicorn api:create_app --factory --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. API и собранный интерфейс обслуживаются одним сервером. После изменений frontend повторите сборку и обновите страницу. Если `dist` создан впервые после старта сервера, перезапустите сервер.

Для разработки запустите backend той же командой, затем **в другом терминале**:

```bash
pnpm dev
```

Откройте http://127.0.0.1:4173. Vite перенаправляет `/api` на backend `127.0.0.1:8000`. `pnpm preview` показывает только статическую сборку; для работы API используйте FastAPI или `pnpm dev`.

Без ключа каталог и калькулятор работают. AI-панель сообщает, что анализ не настроен, а `/api/analysis` возвращает 503. В приложении нет подставного ответа модели или автоматического перехода на демо-расчёты. Сейчас UI использует только OpenAI; NVIDIA остаётся необязательной возможностью отдельного `LLMRouter`.

## Проверка командой

1. Нажмите **«Загрузить план из задания»**. Он содержит две социальные меры и допустим по правилам.
2. Дождитесь расчёта: расходы **95**, остаток **5**, Score **52.55768 → 56.54307**, изменение **3.98539**, критических показателей **2 → 0**.
3. Нажмите **«Объяснить результат с AI»**. Должны появиться общая оценка, сильные стороны, риски и штрафы, рекомендации.
4. Измените район одной меры. Калькулятор выполнит новый запрос, старый AI-анализ будет помечен как устаревший. Если анализ ещё выполнялся, браузер отменит ожидание ответа.
5. Нажмите **«Собрать питч»** после актуального анализа. Слайды собираются по шаблону из того же серверного результата и проверенного ответа модели, без дополнительных расчётов и обещаний эффекта.

Также проверьте выбор без района, превышение бюджета, третью меру одной категории и несовместимые пары. UI даёт раннюю подсказку, а сервер независимо проверяет весь набор.

## API

Интерактивный контракт: http://127.0.0.1:8000/docs.

| Метод | Адрес | Результат |
| --- | --- | --- |
| GET | `/api/catalog` | Нормализованный датасет, правила, названия показателей, пример плана, признак настройки AI |
| POST | `/api/simulate` | Детерминированный `SimulationResult`, версия схемы `2.0` |
| POST | `/simulate` | Совместимый адрес того же калькулятора |
| POST | `/api/analysis` | `{ "simulation": SimulationResult, "assessment": Assessment }` |

Оба POST принимают **только** идентификаторы мер и назначения районов:

```json
{
  "measure_ids": ["M7", "M8", "M10", "M12", "M5"],
  "district_assignments": {
    "M7": "nura",
    "M8": "nura",
    "M10": "nura",
    "M5": "saryarka"
  }
}
```

У общегородской M12 нет назначения района. Корректный ID Байконура — `baikonur`. Передавать клиентские стоимости, итоговые Score или произвольный промпт нельзя: лишние поля отклоняются. `/api/analysis` повторно рассчитывает план на сервере перед передачей в LLM, даже если клиент уже вызывал `/api/simulate`.

```bash
curl -s http://127.0.0.1:8000/api/simulate \
  -H 'Content-Type: application/json' \
  --data-binary @examples/official_request.json
```

Невалидный запрос возвращает 422. Бизнес-ошибки находятся в `detail.validation_errors`; ошибки структуры — в стандартном `detail` FastAPI. Отсутствие AI, таймаут, отказ провайдера или непрошедший проверку ответ дают 503 без сырых сообщений провайдера и ключей. Математический результат остаётся доступен независимо от AI.

`examples/response.json` соответствует `examples/request.json` (другой допустимый план: расходы 81, Score 54.767805).

## Правила калькулятора

- Бюджет 100 у.е.; ровно 5 уникальных мер; не более 2 мер из одного направления.
- Районная мера применяется к одному явно выбранному району. Общегородская — ко всем районам с однократной оплатой.
- Горизонт 8 кварталов, эффект меры умножается на `(8 − lag) / 8`.
- Суммируются эффекты и синергии, затем каждый показатель ограничивается диапазоном 0–100.
- Все десять показателей направлены одинаково: больше означает лучше.
- Индекс района `D` — взвешенная сумма его показателей; веса в `data/rules.json`.
- `D_avg` — средний индекс с весами по населению.
- `Score = 0.7 × D_avg + 0.3 × min(D) − N_crit`.
- `N_crit` считает все пары «район — показатель» со значением строго ниже 40. Штраф вычитается из городского Score без весов населения. Сам Score не ограничивается диапазоном 0–100.

`score_breakdown` раскрывает компоненты Score; `measure_contributions` — эффекты мер и синергий; `penalties` — критические показатели до/после. Поле `penalty` района показывает его вклад в городской штраф, а не вычитание из районного индекса. `base_d` исходного датасета остаётся справочным значением; расчёт использует десять метрик и заданные веса.

Серверные пути можно переопределить через `CITY_DATA_PATH` и `CITY_RULES_PATH`. Датасет и правила валидируются при создании приложения. Изменение JSON требует перезапуска backend.

## LLM-модуль

`llm_integration.py` отдельно от HTTP-слоя. Используйте один экземпляр `LLMRouter` на приложение и закрывайте его при завершении:

```python
from llm_integration import LLMRouter

async def explain(calculator_result):
    async with LLMRouter.from_env() as router:
        return await router.assess(calculator_result, provider="openai")
```

Сам `from_env()` читает переменные процесса. FastAPI и CLI-пример предварительно загружают `.env`. Для отдельного вызова с готовым JSON:

```bash
python -m examples.explain examples/response.json
```

`Assessment` содержит ровно четыре поля:

```json
{
  "general_assessment": "Общая оценка",
  "strengths": ["Сильная сторона"],
  "risks_and_penalties": ["Риск или штраф"],
  "recommendations": ["Качественная рекомендация"]
}
```

OpenAI вызывается со strict JSON Schema. Перед выводом сервис проверяет структуру, запрещает буквальные числовые значения в ответе и разрешает ссылки `{{number:N}}` только на значения из входного JSON, затем подставляет исходные числа. До завершения этих проверок текст не попадает в UI. Это ограничивает выдуманные числовые значения, но не доказывает правильность смысловой интерпретации: AI-текст нужно сверять с таблицей и расчётом.

На попытку отводится 20 секунд, общий лимит роутера 45 секунд; скрытые повторы SDK отключены. Браузер ограничивает ожидание 50 секундами и игнорирует результаты отменённых запросов. Отмена в браузере не гарантирует остановку уже принятого провайдером запроса.

Для отдельного использования NVIDIA нужны `NVIDIA_API_KEY` и точный `NVIDIA_MODEL`. `NVIDIA_BASE_URL` и `NVIDIA_OUTPUT_MODE` выбираются по возможностям конкретного endpoint (`json_object`, `json_schema` или `nvext`). Fallback включается явно: `router.assess(result, provider="openai", fallback="nvidia")`. Веб-приложение NVIDIA не инициализирует.

## Автоматические проверки

```bash
python -m pip install pytest httpx
python -m pytest -q
pnpm test
pnpm build
```

Python-тесты проверяют формулу, штрафы, порог критичности, строгий JSON, числовые ссылки, fallback/таймауты и цепочку API → калькулятор → LLMRouter с тестовым провайдером. JS-тесты проверяют правила выбора и изменение ключа плана при смене района. Тесты не отправляют платные запросы в OpenAI.
